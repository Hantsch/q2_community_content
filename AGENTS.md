# Repository language

Use English for all repository-authored content, including documentation, code
comments, manifest descriptions, and commit messages. This applies regardless of
the language used in the conversation. Preserve original third-party license texts
and proper names.

# Repository boundary

The published surface — `news/`, `engines/`, `gamedata/`, `packs/`, `mods/` and
`config_templates/` — is content only and carries no presentation (no CSS, HTML,
colours, fonts or layout); the launcher fetches it and owns how it looks. `studio/`
is local tooling that runs on the contributor's machine and is never fetched by the
launcher.
